# ⚡ متجر عطور بَـرْق | BARQ PARFUMS

مرحباً بك! تم بناء هذا المتجر الإلكتروني الفاخر بالكامل لبراند **عطور بَـرْق (BARQ PARFUMS)** استناداً إلى هويتك وشعارك، وتصميمه لينافس كبرى مواقع العطور مع نظام الشراء المباشر عبر الواتساب ولوحة تحكم متكاملة.

---

## 🚀 كيفية تشغيل المتجر بنقرة واحدة

1. اضغط مرتين (Double Click) على ملف:
   ```
   start_barq.bat
   ```
2. سيتم فتح المتجر تلقائياً في متصفحك على الرابط:
   👉 **http://localhost:8000**
3. وللدخول إلى لوحة التحكم:
   👉 **http://localhost:8000/admin.html**
   - **رمز الدخول السري الافتراضي (PIN):** `1234` (يمكنك تغييره من الإعدادات).

---

## 🌟 مميزات المتجر للعملاء

1. **تصميم فاخر وعصري (Luxury Aesthetic):**
   - متناسق مع الشعار الأزرق الكوني والكهربائي مع لمسات ذهبية ملكية.
   - يدعم الهواتف والشاشات الكبيرة بسلاسة فائقة.
2. **اختيار الأحجام والتسعير التفاعلي:**
   - لكل عطر 4 أحجام: **(10 مل تستر · 30 مل · 50 مل الأكثر طلباً · 100 مل ملكي)**.
   - النقر على أي حجم يغير السعر المعروض فوراً.
3. **تفاصيل والهرم العطري لكل عطر:**
   - نافذة منبثقة تستعرض نوتات القمة والقلب والقاعدة ونسبة التركيز والثبات.
4. **سلة شراء ذكية وكوبونات خصم:**
   - تدعم تطبيق كود الخصم (كود ترحيبي تجريبي: `BARQ10`).
   - حساب فوري لمصاريف الشحن بناءً على المحافظة المختارة.
   - شحن مجاني تلقائي عند تخطي الحد الأدنى للطلب.
5. **إتمام الطلب التلقائي عبر واتساب (WhatsApp Checkout):**
   - يدخل العميل اسمه، هاتفه، المحافظة (جميع محافظات مصر الـ 27)، العنوان بالتفصيل، وأي ملاحظات.
   - بضغطة زر واحدة، يتم توليد رسالة واتساب منسقة ومحترفة بكافة تفاصيل الطلب وتوجيه العميل مباشرة إلى رقم الواتساب الخاص بك لإرسالها!

## ⚙️ مميزات لوحة التحكم (Admin Panel)

من خلال الرابط: `http://localhost:8000/admin.html`
- **إضافة عطور جديدة:** اسم العطر بالعربي والإنجليزي، الوصف، المكونات، الأسعار لكل حجم، والشارات المميزة.
- **تعديل المنتجات والأسعار:** تغيير الأسعار في أي وقت وحفظها فوراً لتظهر في المتجر مباشرة.
- **حذف العطور:** حذف أي عطر غير متوفر بنقرة واحدة.
- **رفع الصور:** إمكانية رفع صورة العطر مباشرة من جهاز الكمبيوتر أو وضع رابط خارجي.
- **ربط رقم الواتساب:** إمكانية تغيير وتحديث رقم الواتساب المستلم للطلبات في ثانية واحدة مع زر تجربة مباشر.
- **تعديل أسعار الشحن والشحن المجاني:** تحديد سعر شحن القاهرة والجيزة، الدلتا والإسكندرية، والصعيد، والحد الأدنى للشحن المجاني.
- **سجل الطلبات الواردة:** استعراض أي طلب يتم تسجيله في الموقع مع بيانات العميل والمنتجات لمتابعة حالة الشحن.
- **النسخ الاحتياطي:** تحميل وحفظ كافة منتجاتك وإعداداتك في ملف JSON بنقرة واحدة.

## 🌐 نشر الموقع على الإنترنت (أونلاين)

المتجر مبني بتقنيات الويب الحديثة (Modern Vanilla JS & REST API)، وهو مصمم ليعمل بطريقتين:
1. **محلياً على جهازك:** عن طريق تشغيل `server.py` مع حفظ الملفات التلقائي.
2. **أونلاين مجاناً:** يمكنك رفع ملفات المشروع إلى أي منصة استضافة مثل:
   - **Netlify / Vercel / GitHub Pages / Cloudflare Pages:**
     (المتجر يحتوي على وضع LocalStorage مدمج تلقائياً، بحيث يعمل أونلاين بكامل مميزاته وحفظ المنتجات حتى على الاستضافات الثابتة!).
   - **Render / Railway / PythonAnywhere:**
     (لتشغيل السيرفر وحفظ الملفات سحابياً بالكامل).
